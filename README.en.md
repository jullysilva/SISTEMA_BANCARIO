# Banking System

[🇧🇷 Português](README.md) | 🇺🇸 English

Terminal-based banking system in **Python**, built step by step in [DIO](https://www.dio.me/) challenges. Each file is an evolution of the same system, applying a new language concept.

## Features

- Customer registration (CPF, name, birth date and address)
- Checking account creation and listing (branch `0001`)
- Deposit, withdrawal and statement
- Withdrawal rules: up to **R$ 500.00** per operation and **3 withdrawals** per day

## Challenges

| File | Concepts |
|---|---|
| `1#desafio-estrutura-de-dados.py` | Lists, dictionaries and functions with positional-only (`/`) and keyword-only (`*`) arguments |
| `2#desafio-decoradores-geradores-iteradores.py` | Transaction log decorator, report generator and account iterator |
| `3#desafio-manipulando-arquivos.py` | Writing the transaction log to `log.txt` |
| `4#desafio-gerenciamento-pacotes.py` | Organizing the code with packages and dependencies in mind |

## Getting started

Requirement: **Python 3.8+**. No external dependencies.

```bash
python "1#desafio-estrutura-de-dados.py"
```

Change the file name to run the other challenges. The interactive menu shows up in the terminal.
